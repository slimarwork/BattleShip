# Морской бой

Веб-игра «Морской бой» по правилам русской версии: можно играть против компьютера или онлайн с другом по коду комнаты. Сделана для второго этапа отбора Narxoz Incubator 2026.

**Играть:** https://battleship-7b798.web.app
**Репозиторий:** https://github.com/Slimarwork/BattleShip

## Что умеет игра

- Поле 10×10 и классический флот: один четырёхпалубный, два трёхпалубных, три двухпалубных и четыре однопалубных корабля.
- Расстановка вручную (клик по клетке, поворот кнопкой или клавишей R, подсветка допустимых клеток) или случайная.
- Правило «корабли не касаются даже углами» проверяется и при ручной, и при случайной расстановке.
- Ходы: «мимо», «ранил», «убил». Попал, значит стреляешь ещё раз. Повторный выстрел в ту же клетку невозможен. Вокруг потопленного корабля клетки отмечаются автоматически.
- Победа и поражение, экран результата, «Новая игра».
- **Режим против компьютера.** Бот ищет корабли «в шахматном порядке», после попадания обстреливает соседние клетки, а когда направление корабля понятно, добивает вдоль него. Бот видит только результаты своих выстрелов и не смотрит на вашу расстановку.
- **Онлайн-режим с другом.** Вход через аккаунт Google, создание комнаты с кодом из 5 символов, вход в комнату по коду, ходы в реальном времени.
- Главное меню, адаптивная вёрстка под телефон.
- Партия сохраняется: после обновления страницы игра с компьютером и онлайн-партия продолжаются с того же места.

## Чем отличается

В онлайн-режиме расстановка кораблей **никогда не отправляется на сервер**. Игрок, который стреляет, пишет в комнату только координату выстрела. Защищающийся сам проверяет попадание на своём устройстве и отвечает «мимо / ранил / убил» (для потопленного корабля передаются его клетки). Поэтому подсмотреть чужие корабли через инструменты браузера нельзя.

## Технологии

- HTML, CSS и чистый JavaScript, без сборки и фреймворков.
- Firebase: Authentication (вход через Google), Realtime Database (комнаты и обмен ходами), Hosting (публикация).
- LocalStorage для сохранения партий.

## Запуск на своём компьютере

Игру с компьютером можно открыть двойным кликом по `index.html`. Для онлайн-режима и входа через Google нужен адрес `http://`, а не `file://`:

```
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Чтобы подключить собственный проект Firebase:

1. Создайте проект, включите вход через Google (Authentication → Sign-in method) и создайте Realtime Database.
2. В правилах базы укажите:
   ```
   { "rules": { "rooms": { "$code": { ".read": "auth != null", ".write": "auth != null" } } } }
   ```
3. Впишите значения `firebaseConfig` вашего веб-приложения в `firebase-config.js`.

## Ограничения

- Онлайн-режим рассчитан на двух игроков. Если один игрок выходит в меню, комната закрывается для обоих.
- Результат выстрела в онлайн-режиме определяет устройство защищающегося игрока, а сервер ходы не проверяет. Правила базы данных разрешают запись любому вошедшему пользователю. Для учебного проекта этого достаточно, для реального продукта нужна проверка на сервере.
- Уровни сложности бота, статистика и рейтинги не реализованы.
